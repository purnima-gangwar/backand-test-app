# Backend Test App:

This is a Node.js backend application built for testing APIs and learning backend development. It includes basic API setup with Swagger documentation.

## Tech Stack:
- Node.js
- Express.js
- Swagger UI
- JavaScript

## Setup & Installation:
1. `cp .env.example .env` va `.env` faylini tahrirlash
2. `npm install`
3. `npm run dev` (yoki `npm start`)

 ## Features
- REST API setup using Express.js
- Swagger API documentation
- Environment variable support
- Basic backend structure for testing APIs

Server ishga tushganda brauzer avtomatik ravishda `http://localhost:5000/swagger` ochiladi.
